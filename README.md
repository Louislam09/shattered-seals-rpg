# Shattered Seals RPG

A third-person 3D action RPG featuring real-time combat, extensive skill trees, dungeon crawling, and multiplayer capabilities.

## Features

- **Action Combat**: Real-time third-person hack-and-slash combat with combos and special abilities.
- **Character Classes**: Multiple playstyles, talent trees, spell mechanics, and gear progression.
- **Dungeon Crawling**: Challenging mob encounters, instanced dungeons, and multi-phase boss fights.
- **Multiplayer Ready**: Architecture supporting both single-player exploration and online co-op.

## Getting Started

### Prerequisites
- Godot / Engine environment with C++ modules configured.

### Running the Project
1. Clone the repository:
   ```bash
   git clone git@github.com:Louislam09/shattered-seals-rpg.git
   cd shattered-seals-rpg
   ```
2. Open the project in the engine and run the main entry point.
